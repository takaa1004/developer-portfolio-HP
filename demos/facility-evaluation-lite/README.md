# 事業所評価 自動算出(簡易デモ)

事業所の月次実績CSVを、Excelのルール表に従って評価し、算出根拠つきのExcelを出力する簡易デモです。
架空のデータ・仮のルールで動いています。実際の評価ルールに合わせて設計・作り込む前の、完成イメージの確認用です。

## できること

1. 事業所マスタと月次実績(CSV)を読み込む(UTF-8 / Shift-JIS どちらも可)
2. ルール表(`rules/評価ルール.xlsx`)の基準値で、事業所ごとのスコアとランクを出す
3. 開設直後・実績の欠損・入力ミスの疑いを例外条件として判定し、「参考評価」「要確認」に振り分ける
4. 結果をExcelに出力する

| 出力シート | 内容 |
|---|---|
| 事業所別評価 | 当月・6ヶ月平均のスコアとランク、判定、適用ルール、順位 |
| 算出根拠 | 事業所×月×指標ごとの実績値・計算式・基準値・基準値表の行番号・達成率 |
| 要確認一覧 | 人が確認する項目と、確認者・確認結果・確認日の記入欄 |

## ポイント

- **ルールはExcelで編集できます。** 基準値、ランクの境目、例外条件を変えても、プログラムの修正は不要です。
- **算出根拠が残ります。** どの実績値とどの基準値からスコアが出たのかを、すべて追えます。
- **計算にAIは使いません。** 同じ入力とルールからは必ず同じ結果になります。
- **判断できないものは人に回します。** 例外に当たったものは要確認一覧に載せ、順位の対象から外します。

## 使い方

```bash
pip install pandas openpyxl
python generate_sample_data.py     # サンプルデータとルール表を作る
python evaluate.py --month 2026-09 # 評価を実行(output/ にExcelが出力される)
```
